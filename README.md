## Принцип работы

- Все игровые решения судятся человеком: ИИ готовит предварительный разбор, администратор проверяет и утверждает окончательные изменения.
- Автоматическое судейство и самостоятельное применение игровых эффектов не используются.
- Стартовые JSON и версии правил фиксируются в Git; история Git позволяет сравнивать и возвращать прежние снимки.
- Игровые состояния сохраняются только после утверждения и проверок. Указатель HEAD меняется последним.
- Google Таблицы игроков и страницы сайта — производные публичные представления, без секретных данных.
- При смене года исторические результаты после 01.01.1955 не наступают автоматически.

## Утверждённые дополнения к национальным механикам

Читать `modules/APPROVED_EXTENSIONS.json` и вложенные ссылки **после** `HEAD.json`, манифеста и базовых модулей. С 24.10.2026 два файла индекса/британского дополнения зарегистрированы внутри официального 32-файлового манифеста с SHA-256. Все 12 базовых `modules/{ID}.json` также ссылаются на утверждённые публичные страницы; старые литературные правила остаются контекстом, без автоматических численных эффектов. При выпуске следующего года переносить или явно отменять их в рамках `STATE_WORKFLOW.md`.

С 20 октября 2026 года действует утверждённый британский торгово-валютный модуль `modules/GBR_1955_trade_regimes_approved.json`. Его числовые распределения являются утверждённой игровой оценкой, но не исторической статистикой валюты каждой сделки.

## Военная стартовая оценка RC0.10

В `countries/{ID}.json` хранится `military.equipment_inventory_1955`: 15 категорий, общее количество, боеготовые и три поколения. `industrial_military_capacity_1955` — теоретический потенциал производства, не гарантированный выпуск. 12/12 стран утверждены пользователем для игрового старта 24.10.2026 как **сценарная оценка**, не точные исторические архивные инвентари. Требуются отдельные судейские решения о фактических поставках, размещении, снабжении и мобилизации. Числа нельзя удваивать, добавляя боеготовые и поколения поверх общего парка.

### Длительность хода

Один игровой год = 7 реальных дней: 3 дня посты + 4 дня судейство; базовое окно апелляций 48 часов входит в судейские дни. Точные часы и дата открытия первого хода определяются администрацией. `HEAD.phase=PREPARE`, `campaign_config.public_launch_ready=false` пока первый ход не открыт.
