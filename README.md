# ВПИ 1955 — приватное игровое состояние

Приватный репозиторий кампании `VPI1955_MAIN`, игровой год 1955, старт 01.01.1955.

**Важно:** репозиторий содержит служебное состояние, не предназначенное для игроков. Публичный сайт и его репозиторий: https://github.com/ivgl/VPG1955 — отдельный проект.

## Принцип работы

- Все игровые решения судятся человеком: ИИ готовит предварительный разбор, администратор проверяет и утверждает окончательные изменения.
- Автоматическое судейство и самостоятельное применение игровых эффектов не используются.
- Стартовые JSON и версии правил фиксируются в Git; история Git позволяет сравнивать и возвращать прежние снимки.
- Игровые состояния сохраняются только после утверждения и проверок. Указатель HEAD меняется последним.
- Google Таблицы игроков и страницы сайта — производные публичные представления, без секретных данных.
- При смене года исторические результаты после 01.01.1955 не наступают автоматически.

## Стартовый релиз

Официальный базовый набор: `VPI1955-1955-START-R1`. Оригинальный `HEAD.json` и манифест скопированы побайтово из Google Drive; исходный SHA-256 манифеста: `d310f7d9006b6cfb9141e63619ff1a9919ee4930ecec107be82cc51e825bfa7d`.

Проверка после загрузки: `python3 scripts/verify_release.py`.

**Миграция завершена:** GitHub `ivgl/VPG1955-state@main` — текущий источник истины. Реквизиты Drive в импортированном HEAD сохранены для происхождения и восстановления. Старый официальный HEAD Drive не изменён. См. `STATE_WORKFLOW.md` и `MIGRATION_STATUS.json`.

Папка оригинального релиза: https://drive.google.com/drive/folders/1T13GK2q--rFg871dOhuxzM3I3TJamskh

## Утверждённые дополнения к национальным механикам

Для дополнений, одобренных после фиксации неизменяемого стартового релиза, читать `modules/APPROVED_EXTENSIONS.json` и перечисленные в нём файлы **после** `HEAD.json`, манифеста и базовых модулей. Эти дополнения — часть утверждённых механик; они не переписывают стартовые файлы, не меняют HEAD и не проводят судейство автоматически. При выпуске следующего года переносить или явно отменять их в рамках `STATE_WORKFLOW.md`.

С 20 октября 2026 года действует утверждённый британский торгово-валютный модуль `modules/GBR_1955_trade_regimes_approved.json`. Его числовые распределения являются утверждённой игровой оценкой, но не исторической статистикой валюты каждой сделки.
